# Locked In

Fantasy-league habit tracking for people who need more than willpower.

Locked In turns self-improvement into friendly competition. Create a private league, set a shared weekly goal, and race your friends on daily leaderboards — with real stakes you choose together.

## Why

We know what we should be doing — studying, working out, sleeping better — but solo habit apps make it easy to quit with no one noticing. Locked In adds peer accountability, collaborative goals, and light competition so building habits feels social, not solitary.

## How it works

1. **Form a league** — Invite up to 15 friends into a private group.
2. **Set a group goal** — Everyone works toward the same weekly objective.
3. **Compete daily** — Earn points for progress, completed goals, streaks, and group contributions.
4. **Crown the month** — Highest score becomes **MVP**. Lowest gets **Chud of the Month**.
5. **Settle up** — Leagues pick their own rewards (cash pot, winner’s dinner covered, group outing) and last place completes a "punishment" the group invented.

## Features

- Private leagues with custom size (up to 15 members)
- Shared weekly goals + individual progress
- Daily leaderboards and streak tracking
- Monthly MVP / Chud of the Month titles
- Group-defined rewards and punishments

## Tech stack

- React + TypeScript
- Vite
